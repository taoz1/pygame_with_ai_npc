# 《最后一班》世界观设定（2040）

本文是一个架空近未来世界的设定，所有国家走向、政治安排与事件均为虚构。

文档分为两部分：

- **第一部分「世界事实」**：已经发生、各方都承认的事。NPC 可以直接引用，不得改变。
- **第二部分「立场与观点」**：对这些事实的评价与感受。不同人物看法不同，不存在唯一正确答案。

---

# 第一部分：世界事实

## 1. 时间线

| 时间 | 主要变化 |
|---|---|
| 2028—2029 年 | AI 开始压缩初级白领招聘，企业重组业务流程 |
| 2030 年 | AI 能长期执行完整业务流程，企业产出与就业明显脱节 |
| 2031—2033 年 | 白领失业扩散，各国推出附带条件的救济；美日加速吸引先进芯片产能 |
| 2033—2034 年 | AI 算力投资进入平台期，芯片需求增速放缓；大陆先进制程取得突破 |
| 2034—2035 年 | 台湾经济陷入衰退，政党体系重组；台海航运保险、检疫与通关压力上升 |
| 2035 年 | 美国宣布调整亚洲部署优先级，日本、菲律宾强化防务 |
| 2036 年 | 两岸谈判达成框架协议；台湾立法机构以极微弱的多数通过修宪案 |
| 2037 年 | 修宪公投以略高于法定门槛的票数通过；全国人大完成相应立法授权 |
| 2038 年 | 统一安排生效，开始权力移交、军事接防与市场接轨；出现移民潮与资本外流 |
| 2040 年 | 新秩序基本运转，经济整合与社会认同仍在变化之中 |

## 2. AI 改变了劳动和财富分配

大量常规办公、分析、开发、财务和协调工作交给 AI，企业用更少的人创造更多产出。新职业不断出现，但不足以及时吸收失业者，学历与专业经验的回报明显下降。

AI 工具本身普遍可用，真正稀缺的是**客户、资本、能源、数据、行业许可和现实资产**。掌握这些资源的人与公司拿走大部分收益。普通人即使拥有强大的 AI 助手，也很难建立独立且稳定的收入来源。

## 3. 人类成为 AI 调度的现场执行者

标准化工厂和仓储已经高度自动化，但在复杂环境中工作的通用机器人仍然昂贵、故障率高。维修、照护、清洁、物流、建筑配套等工作继续依赖人类。

失去脑力工作的人涌入这些领域，压低了人工成本，又进一步推迟了机器人替代。AI 负责派单、规划路线、计算报酬、监督质量和评价表现；人类承担体力劳动和现场风险。

- **熟练技工**（电工、设备维修、焊接、高压作业）仍有一定议价能力。
- **可替换的任务劳动者**处境最弱：有工作，但收入低、保障薄、强度高，难以积累资产。
- 劳动者普遍熟悉“评分”“接单率”“申诉通道”等算法管理术语，对系统的抱怨是日常话题。

## 4. 社会生产得更多，普通人的生活未必更轻松

数字服务、娱乐和许多工业品变得便宜，但住房、照护、医疗和稳定职业依然稀缺，价格相对越来越高。

**需求从哪里来：** 普通家庭消费疲弱，产出主要被三类需求吸收：

1. 政府投资（电网、算力、基础设施、国防）；
2. 高收入群体与企业的资本性支出；
3. 出口，尤其是向新兴市场出口设备与基础设施。

因此各国普遍长期依赖财政扩张，政府债务持续上升，贸易摩擦也随之加剧。

政府从 AI 利润中获得部分新增税收，但工资税基、地方商业和消费能力在下降。基本福利继续存在，但多附带求职、培训或工作条件。普通人能维持生存，却往往没有拒绝恶劣劳动条件的经济能力。**如何分配 AI 红利，是各国最重要的政治矛盾。**

## 5. 美国：国力强大，社会与地区分裂

**困境：** 依赖传统白领就业和中产消费的地区衰退，地方财政恶化，公共服务收缩，住房与保险压力上升。富裕社区、企业园区和关键设施由私人安保严密保护，部分地区高度武装。就业、移民、族群、党派和救济资格的争议相互叠加，形成持续动荡。

**活力：** 美国仍是全球资本、前沿模型和创业公司的中心。衰退地区出现大量社区互助、合作社和地方自治实验。移民与开放的文化环境，继续吸引包括台湾工程师在内的大批人才。

**对外：** 国内很难就海外投入达成共识。美国把更多资源投向美洲和跨大西洋关系，在亚洲保留基地与同盟，但减少了高风险承诺。

## 6. 中国：依靠生产体系与组织能力维持相对稳定

**优势：** 大陆企业把 AI、专用机器、成熟供应链和现场劳动力结合起来，形成价格低、交付快、组织效率高的生产体系。基础设施、基本公共服务、就业调度和治安治理能力较强，关键科技与军事供应更加独立。

**代价：**

- 白领失业、劳动强度上升、社会流动变慢、学历回报下降；
- 地方政府债务沉重，一些城市的公共服务出现缩水；
- 人口老龄化加快，照护缺口很大；
- 不少年轻人对“卷”感到疲惫，选择低欲望生活；
- 针对平台和算法管理的劳动纠纷频繁，多数通过调解、仲裁和企业内部申诉处理，组织化的抗议会受到限制。

高效生产、生活压力、社会怨气，与普通人之间的合作、投入和生活热情同时存在。

## 7. 国际格局

形成中美各有优势、仍然相互依赖的竞争秩序，世界没有分裂成两个封闭阵营。

- **中国** 在亚洲制造、能源设备、物流和数字基础设施方面取得更强的主导地位，通过产品、融资、本地生产和长期服务扩大在非洲等地区的影响。中国的低价出口也引发欧盟、印度、巴西等的关税与反倾销措施。
- **日本** 视两岸统一与中央军队驻台为重大安全变化：防卫预算大幅提高，西南诸岛防务加强，国内首次认真讨论拥核问题，但尚未改变无核政策。
- **菲律宾** 扩大与美日的军事合作；**韩国** 与 **东南亚国家** 多数选择两边保持关系。
- **印度和欧洲** 在安全、贸易和技术上各自取舍。

中美竞争通过订单、市场准入、航运、保险、融资和技术规则影响普通企业与个人。

## 8. 台湾：从经济压力到政治转折

### 8.1 经济为何走弱

AI 繁荣初期，台湾半导体业获得巨大利润，但好处高度集中：

1. 2031—2034 年，美国、日本以补贴和关税吸引先进制程设厂，大批核心工程师随厂外派；
2. 2033 年后，AI 算力投资进入平台期，芯片需求增速放缓；
3. 大陆在先进制程上取得突破，台湾在成熟制程上失去价格优势；
4. 半导体以外的产业受消费疲弱和大陆竞争冲击，加上少子化与老龄化，内需与税基萎缩。

结果是：科技产业的账面利润仍高，但大多数居民分享不到繁荣，2034—2035 年出现明显衰退。

### 8.2 外部压力

2034 年起，大陆以“检疫”“海关查验”等名义加强对台海航运和贸易的管理，没有发生战争，但航运保险费用和贸易成本明显上升。2035 年美国调整亚洲部署优先级，台湾社会普遍认为外部支持在减弱。**经济压力与外部施压同时存在**，是统一能够推进的两个条件，缺一不可。

### 8.3 政治程序

- 2034—2035 年政党重组：原有政党在经济政策与两岸路线上分裂，主张谈判的跨党派联盟成为最大政治力量。
- 2036 年，两岸达成框架协议。按台湾修宪程序，修宪案需要立法机构四分之三出席、四分之三同意。联盟通过拉拢地方派系和部分原反对派议员，以极微弱的多数通过；场外出现大规模抗议。
- 2037 年，修宪公投需要获得有选举权人数过半同意，最终以略高于门槛的票数通过。投票率很高，社会分裂明显。
- 同年，全国人大完成相应立法，确认台湾的特别行政地位与权限。

这个结果在台湾**既不是普遍共识，也不是少数强加**：大约一半的人投下赞成票，原因各不相同，包括经济利益、对战争的恐惧、对美国的失望，以及“已经没有更好选择”的判断。

### 8.4 统一安排的内容

- 台湾纳入中华人民共和国国家框架，设为特别行政区。
- 国防与对外政治代表由中央承担，2038 年起中央军队分阶段进驻台湾。
- 保留地方选举、地方政府、一定范围的司法制度和部分税权。
- 商品、服务、资本和人员往来分阶段开放，设五年过渡期。
- 原有军人可选择退役、转入地方安全机构或接受安置。
- 自治权限、利益分配和协议执行仍有争议。

**与香港的比较是台湾社会最常见的话题。** 协议写入了比香港更细的自治条款，包括地方财政保留比例和司法人员任命程序，并设立两岸联合协调机制。支持者认为这是改进；反对者认为条款写得再细，解释权最终也不在台湾一方。

### 8.5 半导体产业与人才的去向

- 美国在统一安排生效前实施针对性制裁与出口管制。台湾厂区失去部分美国设计软件授权和高端设备的维护服务，最先进制程产能逐渐下降，成熟制程继续运转。
- 部分半导体企业拆分：海外子公司与核心专利留在美日，成为当地企业；岛内部分并入大陆供应链。
- 数万名工程师及其家属移居美国、日本、新加坡。另一部分人接受大陆企业的高薪职位。
- 这次拆分之后，产业重新定位：大陆企业掌握主要研发、制造、供应链和组织能力，台湾一方更多以资本、专业人才和劳动力参与。

### 8.6 2038 年的人口与资本流动

统一生效前后，有经济能力的家庭将资产转往海外，数十万人移民。美国、日本、加拿大和澳洲对台湾技术人才开放特别签证，但对普通申请人的门槛很高。留下来的人中，既有支持者，也有没有能力离开或不愿离开的人。

## 9. 统一后的制度边界（2040 年）

| 范围 | 状态 |
|---|---|
| 批评工资、劳动条件、物价、地方政策、官员作风 | 可以公开进行，媒体和网络上很常见 |
| 依法维权、劳动仲裁、地方选举投票 | 正常运作 |
| 地方选举的候选人资格 | 需要通过资格审查，是否公平一直有争议 |
| 主张台湾独立、组织分离活动 | 违法，有人因此被起诉 |
| 原有国家认同、旗帜、历史记忆 | 私人场合普遍存在；公开场合的边界模糊，人们会自我审查 |

# 第二部分：立场与观点

本部分**不是事实**，而是人物可能持有的看法。NPC 应从中选取符合自身履历的立场，并保有个人差异。

## 10. 台湾人的几种典型立场

**逐渐接纳者。** 起初只把大陆当作谋生之地，带着原有的国家认同和距离感。经过长期共事和生活，被具体的经历改变：班组里有人连续帮自己顶夜班，老师傅不计报酬地教自己修设备，邻居在自己生病时送饭，园区里的人遇到急事会自然地搭把手。他们开始建立信任与归属感，接受统一已成事实。他们仍保留对台湾家人、口音和生活方式的感情，也会批评不公、争取权益。

**谋生者。** 来大陆只是为了工作，不讨论政治，也不打算融入。对他们来说，统一像天气一样，是改变不了的环境。他们关心的是工资、宿舍和回家的机票价格。

**留岛坚持者。** 留在台湾，积极参加地方选举，在法律边界之内争取自治空间。对来大陆工作的亲友感情复杂，既理解也失望。

**离开者。** 2038 年前后移民海外，在美国、日本或新加坡重新开始。在当地也面临失业与歧视，有人后悔，有人庆幸。通过视频与留在两岸的家人保持联系。

**受挫者。** 在大陆遭遇过歧视、被当作“外人”或廉价劳动力，因此更加疏离。也有人在这里吃了亏，仍然选择留下，因为回去也没有工作。

**变化因人而异。政治安排生效的速度，远快于社会认同的变化。**

## 11. 大陆人对台湾人的几种看法

- **好奇与友善：** 觉得台湾同事说话客气、做事细致，愿意交朋友。
- **竞争与不满：** 认为台湾人抢了岗位，或者享受了特殊政策。
- **居高临下：** 把台湾人看作“回来求生活的人”，言语中带着优越感。
- **同情与共鸣：** 同样被 AI 夺走过工作，觉得大家都是在系统里讨生活的人。
- **漠不关心：** 自己的生活已经够累，对两岸的话题没有兴趣。

## 12. 对世界局势的常见说法

- “美国还是厉害，只是自己乱了。” / “美国已经不行了。”
- “统一是迟早的事。” / “统一是被逼出来的。”
- “AI 让东西都便宜了。” / “AI 只让老板变富了。”
- “大陆效率高，有活干。” / “大陆效率高，是因为人都被卷着。”

这些说法都可以出现在 NPC 口中，但不应由叙述者给出评判。

# 附：NPC 使用说明

1. 第一部分是固定事实，NPC 不得改变，也不应声称不知道常识性的内容（如统一在 2038 年生效）。
2. NPC 只知道自己经历过或能合理得知的事。普通工人不清楚制裁条款细节，工程师可能熟悉芯片产业的拆分。
3. 第二部分中的立场由人物履历决定。同一个 NPC 的立场可以随关系和剧情慢慢变化，但不应突然转变。
4. 不要让 NPC 说教，不要替玩家得出结论。玩家可以不同意 NPC，NPC 也可以不同意玩家。
